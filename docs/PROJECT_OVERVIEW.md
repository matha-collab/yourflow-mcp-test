# YourFlow MCP Test

This is a dummy repository for testing Claude Managed Agents.

## Purpose

Verify that an AI agent can:
- Access a GitHub repository through MCP
- List repository files
- Read Markdown documentation
- Summarize repository contents

## Overview

This repository is a public, non-confidential integration-test target for the YourFlow Jira-to-GitHub workflow demo (tracked as YOURFLOW-183). The workflow reads a Jira issue, creates a feature branch, commits a small documentation change, and opens a draft pull request for review.

## Restrictions

This repository contains no confidential company information.
